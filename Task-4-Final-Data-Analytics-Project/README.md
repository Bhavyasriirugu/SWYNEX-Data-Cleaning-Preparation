# SWYNEX Final Data Analytics Project

## 1. Problem Statement

Student performance data contains marks across multiple subjects. Analyzing this data manually can make it difficult to identify subject-wise performance patterns and meaningful insights.

This project focuses on analyzing student academic performance data to understand average performance across subjects, identify variations in marks, and present the findings through clear visualizations and an interactive dashboard.


## 2. Objective
The main objective of this project is to analyze student performance data and identify useful academic insights.

The project aims to:

Analyze student marks across different subjects.
Calculate and compare subject-wise average performance.
Identify minimum and maximum marks.
Explore patterns and variations in student performance.
Present the analysis through meaningful visualizations.
Develop an interactive dashboard for easy understanding of the results.

## 3. Dataset Information
The dataset used in this project contains academic performance records of 2,000 students.

The dataset includes marks for the following subjects:

Mathematics
History
Physics
Chemistry
Biology
English
Geography

The dataset was used to analyze student performance and calculate subject-wise average, minimum, and maximum marks.

The dataset was initially reviewed and prepared in Microsoft Excel before performing exploratory data analysis and creating the interactive dashboard.

## 4. Data Cleaning & Preparation
The dataset was reviewed and prepared using Microsoft Excel before performing the analysis.

The following data quality checks were performed:

Checked for missing values.
Checked for duplicate records.
Verified the subject-wise data and values.
Reviewed the dataset for consistency and accuracy.
No missing values were found.
No duplicate records were found.
No major corrections were required.

A separate cleaning log was maintained to document the data validation process.

## 5. Exploratory Data Analysis
Exploratory Data Analysis (EDA) was performed to understand the overall pattern of student performance across different subjects.

The analysis included:

Calculating the average marks for each subject.
Identifying the minimum and maximum marks.
Comparing the average performance across subjects.
Creating visualizations to understand subject-wise performance.
Identifying subjects with relatively higher and lower average marks.

## 6. Interactive Dashboard
An interactive dashboard was created using Microsoft Power BI to present the analyzed student performance data in a clear and user-friendly format.

The dashboard helps users:

View subject-wise student performance.
Compare average marks across different subjects.
Analyze minimum and maximum marks.
Understand overall academic performance through visualizations.
Interact with the data to explore the results easily.

The Power BI dashboard provides an interactive visual representation of the analysis performed during the project.

## 7. Key Insights
The analysis of the student performance dataset provided the following insights:

Mathematics recorded the highest average score of 83.45.
Biology recorded the lowest average score of 79.58 among the analyzed subjects.
Physics and English also showed relatively high average performance, with averages of 81.34 and 81.28 respectively.
The average scores across all subjects were within a relatively close range.
The minimum marks varied across subjects, while most subjects had a maximum mark of 100.

## 8. Business/Analytical Recommendations
Based on the analysis, the following recommendations can be considered:

Identify subjects with relatively lower average performance and provide additional academic support where required.
Encourage students to maintain consistent performance across all subjects.
Use subject-wise performance analysis to identify areas that may require focused learning activities.
Regularly monitor student performance using data-driven reports and dashboards.
Use interactive dashboards to support easier tracking and comparison of academic performance.

## 10. Conclusion
This project provided a complete data analytics workflow, starting from data cleaning and preparation through exploratory data analysis and interactive dashboard development.

The analysis helped identify subject-wise student performance patterns and key insights from the dataset. The Power BI dashboard presents these findings in an interactive and easy-to-understand format.

Overall, the project demonstrates the use of data preparation, exploratory analysis, visualization, and dashboarding techniques to transform raw academic data into meaningful insights.
