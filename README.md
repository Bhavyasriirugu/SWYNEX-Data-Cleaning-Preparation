# SWYNEX – Data Cleaning & Preparation

## Project Overview

This project was completed as part of the **SWYNEX Technologies Data Analyst Internship – Task 1: Data Cleaning & Preparation**.

The objective was to inspect a student performance dataset and identify possible data quality issues before further analysis.

## Dataset

* **Dataset:** Student Performance / Student Scores Dataset
* **Records:** 2,000
* **Tool Used:** Microsoft Excel

## Data Cleaning Performed

The dataset was checked for the following data quality issues:

| Check               | Finding                      | Action Taken        |
| ------------------- | ---------------------------- | ------------------- |
| Missing Values      | No missing values found      | No changes required |
| Duplicate Records   | No duplicate records found   | No changes required |
| Data Types          | Data types are appropriate   | No changes required |
| Inconsistent Values | No inconsistent values found | No changes required |

## Result

After performing the data quality checks, the dataset was found to be clean and suitable for further analysis.

No unnecessary modifications were made to the original data.
